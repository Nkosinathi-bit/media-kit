# Optional backend prototypes

The public creator website is a static HTML/CSS/JavaScript frontend.

- The dotnet folder contains a C# API prototype. Its sample contact endpoint validates a request but does not deliver email or save messages.
- The java folder contains a Maven configuration and a source reference. The reference must be placed in a Java source directory before this starter can be built.

These files are separate from the deployed frontend and are not published by the Pages workflow.
